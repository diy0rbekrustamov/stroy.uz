# Аренда техники и готовность STROY UZ

## Текущий согласованный объём

Пока куратор не подключил сервер, раздел демонстрационный: каталог, фильтры, карточки, предварительный расчёт и формы. Почта, хостинг, PostgreSQL и эквайринг не заказывались и не подключались. Не вводите банковские данные для проверки этого прототипа.

## Интерфейс

- /rentals: отдельный каталог автокранов, самосвалов/КамАЗов и экскаваторов. Фильтрация по типу, городу, оператору, поиск по RU/UZ/EN, сортировка. Фильтры сохраняются в URL; на телефоне панель сворачивается.
- /rentals/:rentalId: изображения, характеристики, оператор, подача, минимальный срок, даты и предварительная стоимость. Обе даты включаются в расчёт. Для демо отправка отключена.
- Ссылки в меню, футере и отдельный блок на главной. /seller/rentals: интерфейс создания объявления для будущего локального API.
- Демонстрационные цены не являются рыночной оценкой. Одна карточка представляет одну машину; количество парка не означает календарь свободных единиц.

## Подготовленная локальная основа сервера

Миграция 002_rentals.sql добавляет rental в listings и ключ повторного запроса. Для заявок переиспользована service_requests с data.kind=rental, поэтому они доступны в кабинетах покупателя и продавца. Новые /api/rentals и /api/seller/rentals дополняют существующий API. POST /api/rentals/:id/requests валидирует контакты, согласие, даты и минимальный срок, считает стоимость на сервере, сохраняет ключ повтора; демо и объявления без владельца отклоняются. При подтверждении владельцем блокируется строка машины и проверяется пересечение с подтверждёнными заявками. Это ещё не договор, оплата, страхование или промышленная система управления парком. Подключение и эксплуатацию согласовать с куратором.

Для сравнения функций рассмотрены официальные материалы [United Rentals FAQ](https://www.unitedrentals.com/our-company/customer-care/faqs) (доставка/самовывоз, управление арендой и расходами), [Home Depot Large Equipment Rental](https://www.homedepot.com/c/large_equipment_rental) (сроки аренды, предварительное резервирование, получение) и [United Rentals Rental Protection](https://www.unitedrentals.com/services/equipment-protection/rental-protection-plan). Эти источники показывают функциональные ориентиры, но не доказывают оценку STROY UZ. Условия иностранных компаний не переносятся автоматически на Узбекистан.

## Чего не хватает в первую очередь

1. **Доверие и реальное предложение:** реальные владельцы, документы компании, фотографии конкретных машин, модель/год/характеристики, проверка состояния, контакты поддержки, модерация объявлений.
2. **Арендные операции:** календарь свободных дат, часы смены и переработка, топливо, оператор, стоимость подачи/возврата, продление/отмена, залог, акт передачи и фиксация повреждений. Подтверждённые заявки должны иметь понятные правила отмены и ответственности.
3. **Торговые операции:** согласованные условия доставки/возврата товаров, платежи и возвраты после выбора провайдера, уведомления по заказам, счета и история операций.
4. **Надёжность:** рабочий сервер куратора, PostgreSQL, HTTPS, SMTP, резервные копии с проверкой восстановления, мониторинг ошибок и ограничение доступа к кабинету управления.
5. **Рост:** серверная фильтрация большого каталога, SEO/индексируемые страницы и метаданные, измерения Core Web Vitals, доступность с клавиатурой/скринридером, отзывы после выполненных заказов, аналитика конверсии с согласованными настройками приватности.

Для начала разумнее качественно запустить один город и три категории техники с несколькими проверенными владельцами, измерить реальные заявки и отказы, затем расширять географию. Международное расширение требует отдельных решений по валютам, регионам, договорам, поддержке и операциям; добавление английского языка само по себе это не решает.

## Проверка и запуск

- npm run dev — интерфейс. Для его просмотра сервер не обязателен: показан демо-каталог.
- npm run api:local — подготовленный локальный API; перед запуском убедиться, что другой процесс не использует .data/postgres. Внешний сервер сейчас не настраивался.
- Тесты: node --test --test-concurrency=1 server/tests/*.test.js scripts/check-*.mjs.
- Новые тесты покрывают даты/расчёт, фильтры/языки, запрет демо-отправки, права владельца, повторную отправку и пересечение подтверждённых заявок.
- Иллюстрации созданы встроенным imagegen; [промпты](rental-images.md), WebP находятся в src/assets/optimized/.

Коммит, push и объединение веток не выполнялись.
