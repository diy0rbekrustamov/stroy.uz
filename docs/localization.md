# Локализация RU / UZ / EN

Интерфейс переводится через `useLanguage()` из `src/i18n/useLanguage.js`.
Русский текст служит ключом, переводы хранятся в `src/i18n/uz.js` и `src/i18n/en.js`.

```jsx
const { t, language } = useLanguage();
<button aria-label={t("Добавить в корзину")}>{t("В корзину")}</button>
```

При добавлении страницы переводите текст, сообщения об ошибках, пустые состояния,
placeholder, alt, title и aria-label. Добавляйте соответствующие строки сразу в оба
словаря. Для новых фраз предпочтительны полные ключи: короткие фрагменты пригодны
только для уже существующих составных сообщений.

Не переводите ввод пользователя, email, URL, ID товаров и значения фильтров.
Демонстрационные названия и характеристики товаров переводятся при отображении;
исходные данные и идентификаторы остаются стабильными.

`matchesProduct(product, query)` ищет по русскому, узбекскому и английскому тексту
одновременно. `productCount(count, language)` учитывает формы числительных.
Каталог, карточка, корзина и избранное используют `src/data/catalogData.js`.

Выбранный язык хранится в `localStorage` под ключом `stroy-uz-language`.
Переключатель поддерживает клавиатуру и `prefers-reduced-motion`. Круговое раскрытие
использует View Transitions API; в остальных браузерах работает анимация индикатора.
Переключение не перезагружает страницу и не пересоздаёт состояние магазина или форм.

Проверки после добавления текста или страницы:

```sh
node --test scripts/check-i18n.mjs scripts/check-merge.mjs
npm run lint
npm run build
```

При добавлении маршрута включите его в проверку рендеринга в `check-merge.mjs`.
Автопроверка находит непереведённый русский текст в EN/UZ, но качество формулировок
и переполнение элементов нужно дополнительно проверять в браузере.
