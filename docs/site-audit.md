# Проверка STROY UZ — 22 октября 2026

Проверены 16 основных маршрутов в браузере при ширине 390 и 1440 px:
главная, каталог, категории, товар, корзина, избранное, вход, регистрация,
восстановление, услуги, услуга, товары продавца, добавление товара,
услуги продавца, добавление услуги, заказы продавца.
Все открываются без ошибки React Router и горизонтальной прокрутки.
Это проверка загрузки и основных сценариев, а не гарантия каждой комбинации действий.

## Исправлено

- Добавлена отдельная страница услуги /services/:serviceId с описанием,
  предварительной сметой, обязательными полями и ограничением даты.
  Неизвестная услуга показывает понятное сообщение и ссылку в каталог.
- Карточки услуг открывают страницу; быстрый калькулятор сохранён отдельно.
- Корзина больше не ведёт на отсутствующий /checkout.
- Формы продавца не выводят персональные данные в консоль и не сообщают
  об успешном сохранении без сервиса.
- Фильтры и поиск товаров продавца теперь фильтруют список.
- Добавлены переводы новых полей продавца и страницы услуги.
- Проверка маршрутов учитывает вложенность: /services и /seller/services
  являются разными адресами, а дубликаты в одном родителе запрещены.

## Что ещё требует реализации

В проекте нет API авторизации, восстановления, оформления заказа,
отправки сметы и публикации товаров/услуг. Эти действия не выполняются.
Пользователь видит сообщение о недоступном сервисе; фиктивного успеха нет.

Редактирование и снятие товаров/услуг с публикации, обработка заказов
в кабинете продавца пока представлены демонстрационными элементами.
Данные кабинета статичны и не синхронизированы с публичными каталогами.
Кнопки этих действий нельзя считать готовым управлением магазином.

Фотографии публичных услуг взяты из имеющихся изображений проекта.
Для точного соответствия макету нужны отдельные фотографии услуг.

## Воспроизведение

- Разработка: npm run dev
- Сборка: npm run build
- Lint: npm run lint
- Автоматические проверки: node --test scripts/check-*.mjs

Остаются прежние предупреждения lint в Sidebar, ShopContext и формах
react-hook-form, а также предупреждение сборки о размере основного JS.
