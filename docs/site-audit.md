# Проверка STROY UZ — обновлено 23 октября 2026

Проверены 16 основных маршрутов в браузере при ширине 390 и 1440 px:
главная, каталог, категории, товар, корзина, избранное, вход, регистрация,
восстановление, услуги, услуга, товары продавца, добавление товара,
услуги продавца, добавление услуги, заказы продавца.
Все открываются без ошибки React Router и горизонтальной прокрутки.
Это проверка загрузки и основных сценариев, а не гарантия каждой комбинации действий.

## Исправлено

- Добавлена отдельная страница услуги /services/:serviceId с описанием,
  предварительной сметой, обязательными полями и ограничением даты.
  Неизвестная услуга показывает понятное сообщение и ссылку в каталог.
- Карточки услуг открывают страницу; быстрый калькулятор сохранён отдельно.
- Корзина больше не ведёт на отсутствующий /checkout.
- Формы продавца не выводят персональные данные в консоль и не сообщают
  об успешном сохранении без сервиса.
- Фильтры и поиск товаров продавца теперь фильтруют список.
- Добавлены переводы новых полей продавца и страницы услуги.
- Проверка маршрутов учитывает вложенность: /services и /seller/services
  являются разными адресами, а дубликаты в одном родителе запрещены.

## Подключённый API

Добавлен Node.js + Fastify + PostgreSQL API. Работают регистрация, вход,
серверные сессии, каталог из базы, создание и редактирование объявлений,
загрузка первого фото, публикация/снятие с публикации, оформление заказа,
заявки на услуги и переходы статусов. Вход в кабинет продавца требует
аккаунта продавца. Заказы и заявки отображаются в /account.

Проверены 18 автоматических тестов, HTTP-сценарий с локальной постоянной
базой и вход через браузер. Проверены реальное фото, изменение цены и
сохранение статуса после перезагрузки. Новые страницы проверены на ширинах
320, 390, 768 и 1440 px. Исправлено переполнение меню продавца на 320 px.

Без API оставлен демонстрационный просмотр. Для реальной работы нужно
запустить оба сервера. Инструкции и точные границы реализации: [API](api.md).

В этой среде использовался PGlite — встроенный PostgreSQL. Подключение к
отдельному PostgreSQL-серверу и доставка настоящих писем здесь не проверены.
Для писем нужны SMTP-настройки. Не реализованы онлайн-платежи, модерация,
подтверждение email, галерея нескольких фото и уведомления о заказах.

Фотографии публичных услуг взяты из имеющихся изображений проекта.
Для точного соответствия макету нужны отдельные фотографии услуг.

## Воспроизведение

- Локальный API: npm run api:local
- Демонстрационные данные (до запуска API): npm run db:seed:local
- Разработка фронтенда: npm run dev
- Сборка: npm run build
- Lint: npm run lint
- Все проверки: node --test server/tests/api.test.js scripts/check-*.mjs

Остаются прежние предупреждения lint в ShopContext и формах
react-hook-form, а также предупреждение сборки о размере основного JS.
