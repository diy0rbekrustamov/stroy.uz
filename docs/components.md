# Общие компоненты витрины

`src/components/ui/ProductCard.jsx` используется на главной, в каталоге,
избранном и рекомендациях товара. Карточка получает исходный объект товара:
переводы применяются внутри, идентификаторы и цены остаются неизменными.

```jsx
<ProductCard
  product={product}
  favorite={favorites.includes(product.id)}
  onFavorite={toggleFavorite}
  onAdd={addToCart}
  headingLevel={3}
/>
```

`onFavorite` получает ID, `onAdd` — объект товара. При `inStock: false` покупка
недоступна. `oldPrice` отображается только при реальной скидке. Уровень заголовка
выбирается по структуре страницы: 2 в каталоге/избранном, 3 на главной/в рекомендациях.
Старый импорт `home/ProductCard .jsx` сохранён для совместимости.

`Button.jsx` поддерживает `primary` (янтарная), `secondary` (тёмная), `outline`
(светлая с обводкой), нативный `disabled`, `type` и ссылку React Router через `to`.
Для кнопки отправки формы нужно явно указать `type="submit"`.

```jsx
<Button onClick={save}>{t("Применить")}</Button>
<Button variant="secondary" to="/catalog">{t("Открыть каталог")}</Button>
<Button variant="outline" disabled>{t("Нет в наличии")}</Button>
```

Общие стили витрины находятся в `ui/storefront.css`, подключённом через `Layout`.
Шапка и футер общие для маршрутов магазина. Не копируйте карточки и их CSS
в новые страницы: используйте компонент и отдельную сетку страницы.
Список корзины и формы кабинета продавца сохраняют свои специализированные элементы.

На телефоне карточки располагаются по две в строке, кнопки покупки растягиваются
по ширине карточки. Фильтры каталога раскрываются отдельной кнопкой; на компьютере
они постоянно видны. Проверяйте длинные названия и RU/UZ/EN минимум на 320 и 390 px.
