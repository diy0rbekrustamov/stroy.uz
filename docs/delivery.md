# Карта доставки

## Запуск

В двух терминалах: `npm run api:local` и `npm run dev`. Для серверного PostgreSQL используйте настройки из основной документации API и `npm run api`. Миграция `003_delivery.sql` применяется общим механизмом миграций при запуске API.

## Сценарий

1. Покупатель добавляет опубликованный товар продавца и открывает `/checkout`.
2. Указывает адрес, телефон, комментарий и необязательную точку на карте. Можно выбрать точку кликом, центром карты, вручную или запросить геолокацию.
3. После оформления открывается `/orders/:orderId/delivery`. Страница также доступна из личного кабинета. Заказ видит только его покупатель.
4. Продавец принимает заказ и создаёт ссылку водителя для своей позиции заказа. Ссылка действует 24 часа; повторная выдача отменяет предыдущую. Доступ можно отозвать.
5. После перевода позиции в статус отправки водитель открывает ссылку на телефоне и явно включает передачу координат. Нужны HTTPS, разрешение геолокации и открытая страница. Браузер может приостанавливать её в фоне.
6. Покупатель видит последнюю полученную позицию выбранной отправки. Обновление — каждые 15 секунд. Позиция старше 90 секунд не обозначается как актуальная. Для разных позиций предусмотрен выбор отправки.

## Ограничения и безопасность

- Нет имитации движения, расчёта дорожного маршрута или обещанного времени прибытия. Без GPS отображаются статус и место доставки.
- Ссылка водителя — секрет доступа: не публикуйте её. Токен находится во фрагменте URL, сервер хранит только его хеш. Он разрешает доступ к адресу одной отправки и передачу координат, но не к профилю покупателя.
- Хранится только последняя позиция, без истории передвижений. Остановка передачи сохраняет последнюю известную позицию; отзыв ссылки очищает её. Завершение/отмена отправки блокирует передачу и скрывает позицию.
- Демо-товары не оформляются через настоящий API. Услуги и аренда используют свои существующие сценарии.
- Карта загружается из OpenStreetMap; адрес можно заполнить и при недоступной карте. Соблюдайте [политику тайлов OSM](https://operations.osmfoundation.org/policies/tiles/). Для публичного сервиса с нагрузкой выберите поставщика с подходящими условиями. URL настраивается через `VITE_MAP_TILE_URL`; при смене поставщика также обновите атрибуцию в `DeliveryMap.jsx`.
- Перед выпуском необходима проверка на реальных телефонах, включая отказ в разрешении, слабый GPS, потерю сети и фоновые ограничения браузера.

## Проверки

`npm run test:api` проверяет сохранение точки, права покупателя/продавца, статусы, свежесть координат, отзыв/замену ссылки и запрет передачи после завершения. `npm run build`, `npm run lint`, `node scripts/check-i18n.mjs` проверяют сборку, код и переводы.
