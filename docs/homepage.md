# Homepage

Главная подключена в `src/App.jsx` через React Router и `src/pages/HomePage.jsx`. Общий `components/layout/Layout.jsx` содержит Navbar, Footer и диалог. Router создаётся один раз вне компонента App.

## Компоненты

- `components/layout/Navbar.jsx`: поиск и навигация; счётчики и обработчики получает через props.
- `components/layout/Footer.jsx`: общие ссылки и информация.
- `components/layout/Brand.jsx`: единый логотип.
- `components/home/Hero.jsx`: первый экран. Встроенная подпись изображения закрыта фоном; исходник изображения сохранён.
- `components/home/Product.jsx`: фильтрация и список товаров.
- `components/home/ProductCard .jsx`: карточка с обработчиками избранного и корзины. Пробел в имени сохранён из существующей структуры; согласуйте переименование отдельно.
- `components/home/HomeDialog.jsx`: нативный dialog, закрытие через Escape, кнопкой и по фону.
- `components/home/homeData.js`: демонстрационные данные товаров, категорий, проектов и статей.

Состояние поиска, корзины и избранного принадлежит Layout и передаётся HomePage через Outlet context. Оно сохраняется при переходах через Link и сбрасывается при обновлении страницы. Товары и цены демонстрационные. Категории показывают соответствующую группу доступных демонстрационных товаров. Разделы без реализации открывают информационный диалог.

Ссылки общих компонентов ведут на секции главной (`/#products`, `/#categories`) или существующую страницу `/login`. Поиск с других страниц возвращает к товарам при отправке формы. Стили главной ограничены её содержимым и общими компонентами, чтобы не переопределять оформление форм авторизации. Регистрация предотвращает стандартную отправку формы до подключения API.

## Стили и ресурсы

Стили главной изолированы классами `home-*` и `.homepage` в `pages/HomePage.css`. Общий `index.css`, Tailwind и конфигурации не меняются. Используется обычный CSS рядом с JSX, как в исходном проекте. Цвета вынесены в CSS-переменные. Файлы React — PascalCase, функциональные компоненты, двойные кавычки и точки с запятой.

Изображения в `src/assets/home/` взяты из предоставленных экспортов. Макеты секций не используются как изображения интерфейса: все тексты, карточки и кнопки реализованы кодом. Шрифт экспортами не указан, используется Arial; мобильная компоновка адаптирована без отдельного мобильного макета. При появлении шрифта и мобильного экспорта их можно сверить и уточнить отдельно.
