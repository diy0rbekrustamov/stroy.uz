# Hero: отдельные материалы

7 PNG с реальной прозрачностью. Общий холст 1265 × 1244 px; прозрачные поля сохранены. Для анимации размещайте слои absolutely в одном контейнере, width:100%, height:100%, object-fit:contain. Порядок сзади вперёд приведён в layers.json.

Это реконструкция через встроенный imagegen из плоского изображения: скрытые поверхности дорисованы, возможны отличия размеров/перспективы. assembly-preview.jpg показывает пробное наложение без ручной подгонки. Для окончательной сборки нужны коррекция положения/масштаба и при необходимости маски в местах взаимного перекрытия. Стекло может потребовать дополнительной настройки прозрачности. Это PNG-слои, не полноценные 3D-модели.

Сайт пока не переключён на эти слои. Полные промпты: docs/hero-layer-prompts.json в корне проекта.
